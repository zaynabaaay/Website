Seal palette — working set (palette C, provisional)

Palette C "Faded Celebration" is adopted as the working seal palette, still provisional until physical sampling (STORIEL_BRIEF.md §9.4). Each seal is a pair: a display tint (blocks, thumbnails, backgrounds — never text) and a text shade — the same OKLCH hue darkened until it passes WCAG AA 4.5:1 against paper. Ratios below are computed live from the token values, so this display cannot drift from css/tokens.css.
